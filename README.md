# **Sami Khan — Portfolio Site 💻**

- Sections: Home, Resume, Projects, Education, About, Contact

- Single-file static site — no build step, no dependencies, no backend

- HTML, CSS, and vanilla JavaScript (one self-contained index.html)
- No frameworks or external libraries required. This runs locally.
- No build tools needed — just open index.html in any modern browser.
