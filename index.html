Projects

burnout_beacon.py
GitHub
Watch demo on YouTube

Burnout Beacon is a web application built to help teams catch the early warning signs of burnout before they escalate. By allowing employees to log daily tasks alongside mood self-assessments, the app analyzes weekly trends across workload density, task difficulty, and sentiment. Managers get access to diagnostic risk reports and visual analytics to adjust team workloads proactively, while employees gain a personal dashboard to reflect on their performance and well-being over time.

Time Series Analysis OOP Python Streamlit JSON
wins4boston.py
GitHub
Watch demo on YouTube

Wins 4 Boston is a sports analytics platform that predicts outcome probabilities for Boston Celtics basketball games. The application ingests raw historical NBA data into a structured relational database, processing team performance metrics. Through an interactive desktop interface, users can run queries to evaluate matchup variables, visualize statistical trends, and inspect win-probability forecasts on demand.

Python Data Modeling Desktop App Sports Analytics
